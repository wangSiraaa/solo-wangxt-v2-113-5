# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm test            # = test:groups + test:seam
npm run test:groups
npm run test:seam
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。

`test:seam` 是接缝审计的无头验收（Node + tsx，纯 TS 软件光栅器，不依赖浏览器）：p1 透明描边跨左右配对边界、单侧移动后失败并定位对象/实例/差异、p6m 超级周期斜向镶嵌边界（含“漏画一个矩阵像而外框完好”必须被斜向边界抓到）、以及运行中编辑/撤销/刷新的过期令牌与旧版本迁移防伪造。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。PNG 导出与接缝审计共用同一份绘制任务枚举（对象×陪集×周期副本）、同一超级周期与基本域裁切，二者描述的最终合成不可能不一致。
- 几何一致的接缝审计：先对群、晶格尺寸、路径命令与样式生成内容指纹（不含 updatedAt 等元数据），再沿超级周期外框平移边与群镶嵌的每条斜向基本域边，在实际导出像素上比较两侧的几何覆盖（α）与预乘透明度颜色；三角/居中晶格检查斜向边而非只测水平/竖直外框。
- 审计状态为 `运行中/通过/失败/过期/错误`，持久化在独立 IndexedDB（含指纹与 schema 版本）。失败会列出边界坐标、差异范围（首末差异站点）、最大 α/颜色差、关联源对象与具体实例 `objectId@coset:n,m`；界面叠加边界与热区，点击热区仍定位到唯一源对象。
- 过期令牌（epoch）：编辑、撤销/重做（即使字节回到旧值）、群切换或自动保存写入内容都会推进指纹与单调 epoch；运行中的旧审计迟到时其结果被丢弃、内容只能显示“过期”，重新审计才可通过。刷新后未完成（running）记录变为过期；旧 schema 或指纹不匹配的记录迁移后也不能恢复为通过。
- 工程以 IndexedDB 本地保存；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。
