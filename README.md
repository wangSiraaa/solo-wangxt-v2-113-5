# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm run test:groups
npm run test:seam
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。

`test:seam` 是“接缝/导出”页接缝审计的验收测试（Node + Canvas/IndexedDB 模拟，无浏览器依赖），覆盖：
p1 跨左右边界透明描边路径通过且与 PNG 重复预览一致、故意移动一侧后失败并定位唯一源对象与实例、
p6m 在 2×2 矩形超级周期的斜向原胞边界通过、运行中编辑/撤销/切换工程的迟到结果只能标为过期、
零不透明度路径仍参与几何检查、旧工程迁移不会伪造通过，以及 PNG 导出保持可用。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。
- 接缝审计与 PNG 导出共用同一条渲染管线：先对群、晶格、路径与样式生成内容指纹，再在超级周期外扩边距里用同一组群矩阵、实例与域裁切渲染；逐对象比较配对周期边界的几何覆盖（填充与描边，透明/零不透明度路径同样参与）以及预乘透明度后的最终颜色。矩形/居中群检查周期矩形的两条框架接缝，三角晶格额外按两条原胞平移检查斜向和平移边界，而不只是水平/竖直像素。
- 审计结果持久化为运行中、通过、失败、过期或错误（IndexedDB v2，新 `seam-audits` 仓储）；失败报告列出边界、采样数、差异比例、颜色/几何 Δ、差异热区及其唯一源对象和具体实例 `objectId@coset:n,m`，点击热区或条目即可定位原始对象。
- 编辑、撤销/重做、群切换、尺寸调整或对象增删都会推进内容版本并使旧审计立即过期；运行中迟到的异步结果按 runId/指纹/内容版本三重校验后丢弃，绝不会把新内容标为通过，只有重新审计才能产生新结论。旧版本数据库升级后没有审计记录，不会伪造通过。
- 工程以 IndexedDB 本地保存；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。
